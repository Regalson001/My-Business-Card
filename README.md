# 📇 Personal Business Card

A clean, responsive HTML & CSS business card project built as part of the freeCodeCamp Responsive Web Design curriculum. This web app displays personal branding details, professional designation, contact information, and social media links.

---

## 🚀 Features

- **Semantic HTML5:** Built using structured tags (`<div>`, `<p>`, `<a>`, `<hr>`, `<h2>`).
- **Custom CSS Styling:** Styled with custom margins, padding, centered layout, and border dividers.
- **Clean Typography:** Uses clean Arial font styling with fallbacks.
- **Social & Contact Links:** Includes direct navigation links to GitHub, LinkedIn, Twitter (X), and personal portfolio.

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
